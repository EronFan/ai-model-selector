# AI Coding Model Selector · AI 编程模型选型指南

> 不看"谁最强"，只看"谁最适合"。
> 在线使用：https://eronfan.github.io/ai-model-selector/

一个纯前端的 AI Coding 模型决策工具：输入项目类型、规模、任务、偏好与主要语言，实时给出三档推荐 + 明确的"不优先"清单，每个结论都附原因。

## 功能

- **项目选择器** — 项目类型(14 类)、规模(4 档)、任务(10 类)、偏好(6 项)、主要语言(中文/英文/混合)、长期 Agent 开关 → 加权评分实时推荐
- **模型能力地图** — 11 个模型家族：定位、标签、10 维雷达图、最适合 Top3、不优先 Top3、详情弹窗(Benchmark + 规格 + 来源)
- **任务速选** — 17 个常见任务一键出推荐
- **AI → 项目反向查询** — 关键词过滤，快速回答"这个模型适合什么"
- **多模型对比** — 勾选 2–4 个模型对比能力 / Context / 价格 / 适合场景
- **匹配热力图** — 26 类项目 × 11 模型,S/A/B/C 四级矩阵
- **成本与 Benchmark** — API 标准价格条形图 + 带来源的官方 Benchmark 摘录
- **深浅色双主题** — 默认浅色,可切换深色(localStorage 记忆)

## 纳入的模型

Claude Opus 5、GPT-5.6 Sol、GPT-5.6 Luna、Grok 4.6、Grok 4.5、Muse Spark 1.2、DeepSeek V4 Pro、DeepSeek V4 Flash、Kimi K3、GLM-5.2、GLM-5.3 Flash

## 推荐算法

```text
项目匹配分 =
  项目类型匹配 × 25% + 任务类型匹配 × 20%
+ 规模/上下文 × 15% + Agent 能力 × 15%
+ 代码能力 × 10% + 专项语言/平台 × 10% + 成本效率 × 5%

· 用户偏好(质量/速度/成本)动态调整权重
· 以中文为主的项目额外叠加中文能力评分(约 15%)
· 表内标注"C 不优先"的模型总分 ×0.55
```

## 数据纪律

- Benchmark 只收录官方/权威来源,不同 harness 不做横向排名
- 价格只显示已公布定价;未收录的不填数字
- "不优先"表示存在明显更优选项,不代表模型不能完成任务
- "项目适配度"是综合判断,不是官方排名

数据更新时间:2026-08-27。数据层与 UI 分离(index.html 内 MODELS / PROJECTS / TASKS 数据常量),新增模型无需改推荐逻辑。
